## FAQ

**2 刀 VPS 是月付还是年付？**
三种都有。RackNerd 的 $1.83/月是年付 $21.99 摊下来的；RakSmart 的 $2.99/月是限量秒杀月付；LisaHost 的 ¥2 是单日试用。Evoxt 的 $2.99/月是标准月付，不需要年付。

**Evoxt 续费会涨价吗？**
官方定价页展示的是标准月付价，没有标注“首年优惠价”，因此不存在首年低价、第二年跳涨的价格结构。续费仍以账单页为准，下单时确认计费周期和总价。

**Evoxt 能解锁 Netflix、TikTok 吗？**
现有资料没有 Evoxt 各机房的流媒体解锁测试，无法给出保证。IP 广播地和原生 IP 是两回事，需要解锁能力的人应该先用最小套餐自测，或者选择明确标注原生 IP 的产品。

**需要备案吗？**
机房在中国大陆以外，不需要 ICP 备案。

**支持支付宝吗？**
不支持。可用信用卡、借记卡、PayPal、Bitcoin 和 USDT（Tron 网络）。

**512 MB 能跑 WordPress 吗？**
能装，但很容易出问题。宝塔加 MySQL 加 WordPress 在 512 MB 上会频繁 OOM，5 GB 存储也放不下插件和图片，这类用途从 VM-1 起步。
